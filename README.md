# 🇮🇳 India Tourism Insights Dashboard

An interactive **Power BI dashboard** designed to analyze India's tourism performance across states, destinations, seasons, and years.

## 🎯 Objective

The objective of this project is to transform tourism data into meaningful visual insights that help understand visitor trends, revenue, destination performance, hotel occupancy, ratings, transportation preferences, and seasonal tourism patterns.

## 📊 Dashboard Highlights

* 👥 Total Visitors: **308M**
* 💰 Total Revenue: **921.73K**
* ⭐ Average Rating: **4.25**
* 🏨 Average Hotel Occupancy: **70.05**
* 📍 Unique Destinations: **5K**
* 🌍 Domestic & International Visitor Analysis
* 🚕 Transportation Preference Analysis
* 🌦️ Weather and Seasonal Visitor Analysis
* 🗺️ State-wise and Destination-wise Analysis
* 📈 Yearly and Monthly Tourism Trends
* 💵 Revenue Analysis by Destination Type

## 🔍 Key Analysis

The dashboard provides interactive analysis of:

* Visitor distribution across Indian states
* Top states and destinations by visitor count
* Domestic vs. international visitors
* Tourism trends from 2020–2024
* Visitor patterns across different months and seasons
* Hotel occupancy across cities
* Destination types and their revenue contribution
* Accessibility scores and visitor ratings
* Weather conditions and their relationship with visitor patterns
* Transportation preferences
